// 01. APA ITU CTF

Capture The Flag

CTF (Capture The Flag) adalah kompetisi cybersecurity di mana peserta memecahkan tantangan keamanan untuk menemukan string tersembunyi yang disebut "flag". Setiap flag memberikan poin, dan tim dengan poin tertinggi memenangkan kompetisi.

🌐
WEB EXPLOITATION
SQL Injection, XSS, CSRF, SSRF, LFI/RFI, dan kerentanan web lainnya yang ada di dunia nyata.
🔢
CRYPTOGRAPHY
Pecahkan cipher, enkripsi lemah, dan protokol kriptografi yang salah diimplementasikan.
🔍
FORENSICS
Analisis file, memory dump, network traffic, dan steganografi untuk menemukan bukti tersembunyi.
💥
BINARY EXPLOITATION
Buffer overflow, ROP chains, format string bugs — eksploitasi program di level mesin.
⚙️
REVERSE ENGINEERING
Bedah binary, decompile aplikasi, dan pahami kode yang sengaja diobfuskasi.
📡
OSINT
Gunakan sumber terbuka untuk menemukan informasi tersembunyi dari internet dan dunia nyata.
